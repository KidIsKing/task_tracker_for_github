## Примерный список функций для защиты Django REST API:

1. добавление истории изменения задач (когда у задачи меняют статус, исполнителя или приоритет)
2. добавление подзадач к уже существующим
3. эндпоинт для возвращения задач, спругпированных по статусу
4. эндпоинт с формированием отчета по проекту (возвращаем количество задач, количество просроченных задач, распределение задач по участникам проекта, последняя дата дедлайна)
5. добавление уведомлений с сообщением о том, что назначена задача
6. добавление кастомных статусов задач для проекта
